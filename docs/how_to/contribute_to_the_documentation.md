# Contribute to the documentation

To update the plugin documentation, edit the markdown files under `packages/plugin-img/docs`.

### Preview documentation locally

From the plugin package root:

```powershell
Set-Location .\packages\plugin-img
mkdocs serve
```

Open the local URL shown in the terminal and verify your changes.

### Recommended documentation updates

- explain supported image folder layouts
- document parser assumptions and fallback behavior
- add examples for running tests and local builds
- keep content short and actionable
